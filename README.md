# 🚀 GOD MODE // NEURAL OVERRIDE

Landing Page com estética cyberpunk focada em impacto visual, performance e experiência imersiva usando apenas HTML, CSS e JavaScript puro.

---

## 📌 Visão Geral

Interface inspirada em terminal futurista, com:

- UI minimalista e agressiva
- Animações leves e fluidas
- Zero dependência de frameworks
- Alta performance client-side

Objetivo: capturar atenção imediata e transmitir poder tecnológico.

---

## 🧠 Stack

- HTML5
- CSS3 (Custom Properties)
- JavaScript Vanilla
- Lucide Icons (ícones)
- Google Fonts (tipografia)

---

## ⚙️ Funcionalidades

### Sidebar Inteligente
- Colapsada por padrão
- Expansão no hover
- Feedback visual ativo

### Hero Section
- Tipografia impactante
- CTA com efeito neon
- Copy orientada a posicionamento tech

### Grid de Features
- Layout responsivo com CSS Grid
- Cards com hover
- Estrutura escalável

### Header Dinâmico
- Relógio em tempo real
- Estética de terminal

### Background Animado
- Canvas com efeito “starfield”
- Animação contínua com baixo custo

---

## 📱 Responsividade

- Desktop: sidebar lateral interativa
- Mobile:
  - Navegação inferior fixa
  - Layout otimizado
  - Simplificação visual

## 🎨 Design System

```css
:root {
  --neon: #ccff00;
  --darker: #050505;
  --surface: #0f0f0f;
  --accent: #1a1a1a;
}
```

Diretrizes:
- Dark mode nativo
- Alto contraste
- Destaque em neon

## ▶️ Como rodar

Abra direto no navegador:

```bash
lapg.html
```

Ou use um servidor local:

```bash
npx serve .
```
